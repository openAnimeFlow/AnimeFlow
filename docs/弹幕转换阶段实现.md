# 弹幕简体/繁体转换阶段实现

> Version: v1.1
>
> Last Update: 2026-08-21
>
> 基于 `flutter_opencc_plus` 实现播放器弹幕简体中文与繁体中文转换。
>
> 当前进度：阶段 0-5 已完成；阶段 6 单元测试已完成，发布验证待执行。

## 零、目标与边界

### 目标

- 弹幕从弹幕源加载后，可以按用户设置转换为简体或繁体后展示。
- 支持“关闭 / 简体转繁体 / 繁体转简体”三种模式。
- 播放过程中切换模式可以即时重新转换当前剧集弹幕。
- 转换只影响展示，不改变发送给服务端的弹幕原文。

### 边界

| 事项 | 做法 |
|------|------|
| 转换时机 | 弹幕加载完成后、进入 `PlayState` 之前 |
| 转换范围 | 只处理拉取到的弹幕，不处理用户发送内容 |
| 数据源 | `Danmaku.originalMessage` 始终保持原始文本 |
| 失败策略 | 转换失败回退原始文本，不允许弹幕丢失 |
| 并发 | `ZhConverter` 不跨 isolate 共享，批量转换在后台 isolate 内完成 |

```dart
import 'package:flutter_opencc_plus/flutter_opencc_plus.dart';

enum DanmakuChineseMode {
  none('none'),
  s2t('s2t'),
  t2s('t2s');

  const DanmakuChineseMode(this.name);

  final String name;

  OpenCCConfig? get config => switch (this) {
    DanmakuChineseMode.none => null,
    DanmakuChineseMode.s2t => OpenCCConfig.s2t,
    DanmakuChineseMode.t2s => OpenCCConfig.t2s,
  };

  static DanmakuChineseMode fromName(String? value) {
    return values.firstWhere(
      (mode) => mode.name == value,
      orElse: () => DanmakuChineseMode.none,
    );
  }
}
```

说明：

- `s2t`：简体转 OpenCC 标准繁体。
- `t2s`：繁体转简体。
- 如果以后要支持台湾/香港常用词，可扩展 `s2twp`、`tw2sp`、`s2hk`、`hk2s` 等配置，不需要改整体架构。

## 三、阶段 2：转换服务

### 目标

封装 `flutter_opencc_plus`，提供批量转换能力，并隔离 FFI 调用和 UI。

建议放在：

```text
lib/features/play/application/danmaku_chinese_converter.dart
```

### 2.1 服务实现

```dart
import 'dart:io';
import 'dart:isolate';

import 'package:flutter_opencc_plus/flutter_opencc_plus.dart';
import 'package:path/path.dart' as p;

import '../../../shared/models/player/danmaku/danmaku_module.dart';
import 'danmaku_chinese_mode.dart';

class DanmakuChineseConverter {
  String? _dataDir;

  /// 触发一次资源解压，并记录 OpenCC 数据目录。
  ///
  /// 当前包会把 Flutter assets 解压到系统临时目录。
  /// 升级 flutter_opencc_plus 后如果路径规则变化，需要同步复核。
  Future<String> _ensureDataDir() async {
    if (_dataDir != null) return _dataDir!;
    final seed = await ZhConverter.create(OpenCCConfig.s2t);
    seed.dispose();
    _dataDir = p.join(
      Directory.systemTemp.path,
      'flutter_opencc_plus_assets',
    );
    return _dataDir!;
  }

  Future<List<Danmaku>> convertDanmakus(
    List<Danmaku> danmakus,
    DanmakuChineseMode mode,
  ) async {
    if (mode == DanmakuChineseMode.none || danmakus.isEmpty) {
      return danmakus;
    }

    final dataDir = await _ensureDataDir();
    final config = mode.config!;
    final messages = [
      for (final danmaku in danmakus) danmaku.originalMessage,
    ];

    try {
      final converted = await Isolate.run(
        () => ZhConverter.run(
          config,
          (converter) => converter.convertAll(messages),
          dataDir: dataDir,
        ),
      );

      return [
        for (var i = 0; i < danmakus.length; i++)
          danmakus[i].copyWith(message: converted[i]),
      ];
    } on Object {
      // 转换失败时保留原始文本，保证弹幕不丢。
      return danmakus;
    }
  }

  void dispose() {}
}
```

### 2.2 转换服务 Provider

在播放相关 provider 文件中注册：

```dart
final danmakuChineseConverterProvider =
    Provider<DanmakuChineseConverter>((ref) {
  final converter = DanmakuChineseConverter();
  ref.onDispose(converter.dispose);
  return converter;
});
```

### 设计说明

- `ZhConverter.run` 会在内部创建、使用、释放 native handle，适合后台 isolate。
- `convertAll` 尽量用一次 native 调用完成整批转换，性能优于逐条 `convert`。
- `ZhConverter` 禁止跨 isolate 共享，因此在 `Isolate.run` 内部创建。
- 资源目录先在主 isolate 初始化，后台 isolate 通过 `dataDir` 直接同步创建转换器，避免在后台 isolate 依赖 `rootBundle`。

### 验收标准

- `none`、空列表、转换失败均原样返回。
- `s2t` 能把“开放中文转换”转成“開放中文轉換”。
- `t2s` 能把“開放中文轉換”转成“开放中文转换”。
- 大批量转换不阻塞 UI。

### 3.4 切换模式时重新转换

在 `PlaySession` 新增：

```dart
Future<void> applyDanmakuChineseMode(DanmakuChineseMode mode) async {
  _danmakuChineseMode = mode;
  final state = _playStateActions.value;
  final all = state.danDanmakus.values.expand((items) => items).toList();
  if (all.isEmpty) return;

  _playStateActions.incrementDanmakuEpoch();
  _clearDanmakuCanvas();

  final converted = await danmakuChineseConverter.convertDanmakus(all, mode);
  final grouped = <int, List<Danmaku>>{};
  for (final item in converted) {
    grouped.putIfAbsent(item.time.toInt(), () => []).add(item);
  }
  _playStateActions.setDanDanmakus(grouped);
}
```

当前实现额外使用 `_danmakuChineseModeRevision` 丢弃过期转换结果：

- 每次切换模式递增代次，异步转换完成后只有最新代次才能回写 `PlayState`。
- `removeDanmaku()` 也会递增代次，避免换集后旧剧集转换结果覆盖新剧集。
- 弹幕渲染层的 `danmakuEpoch` 继续负责丢弃旧延迟回调。

### 3.5 防止旧延迟回调写入旧文本

当前 [danmaku_view.dart](C:/Coding/ProJect/AnimeFlow/AnimeFlow/lib/features/play/presentation/widgets/video/ui/danmaku/danmaku_view.dart:99) 使用 `Future.delayed` 分批加入弹幕。切换模式后旧的延迟回调仍可能执行，因此：

1. 在 `PlayState` 增加 `danmakuEpoch` 字段和 `incrementDanmakuEpoch()`。
2. 在弹幕定时器捕获当前 `danmakuEpoch`。
3. 延迟回调执行前校验：

```dart
final epoch = playState.danmakuEpoch;

Future.delayed(delay, () {
  if (!mounted ||
      epoch != ref.read(playStateProvider).danmakuEpoch ||
      !ref.read(playStateProvider).playing ||
      !ref.read(playStateProvider).danmakuOn) {
    return;
  }
  // ...
});
```

### 验收标准

- 打开剧集后，弹幕按照当前模式显示。
- 切换模式后，当前已加载弹幕立即按新模式重新显示。
- 切换模式不会把旧模式的文本再次画到 canvas。

## 六、阶段 5：边界与性能

### 6.1 发送弹幕

`sendDanmaku()` 不经过 `DanmakuChineseConverter`：

- 用户输入什么，canvas 显示什么。
- 用户输入什么，服务端收到什么。

### 6.2 转换失败

所有转换异常统一回退原始文本：

```dart
try {
  return await _convertInIsolate(...);
} on Object {
  return danmakus;
}
```

### 6.3 可选缓存

当前 `DanmakuChineseConverter` 已内置有界内存缓存：

```text
key: (DanmakuChineseMode, originalMessage)
value: convertedMessage
上限：4096 条，超出后淘汰最早写入的条目
```

注意：

- 缓存只保存当前播放会话，切集或退出播放后释放。
- 弹幕量很大时增加上限，避免内存膨胀。
- 转换失败不写入缓存，下次仍会重新尝试。
- `dispose()` 清空缓存；注入 `batchConverter` 的测试替身也走同一套缓存逻辑。

### 6.4 性能预期

- 弹幕在加载阶段批量转换，渲染阶段零转换成本。
- 大批量转换在后台 isolate 执行，不阻塞 UI 帧。
- 切换模式只需要对当前剧集重新转换一次。
